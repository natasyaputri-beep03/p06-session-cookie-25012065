# Pertemuan 6 - Session, Cookie, dan Keranjang

## Deskripsi

Praktikum PHP tentang penggunaan session, cookie, flash message, dan keranjang sederhana.

## Fitur

- Session untuk keranjang
- Cookie untuk preferensi tema
- Flash message
- Keranjang produk
- Menambah dan menghapus produk
- Mengosongkan keranjang
- Validasi input

## Cara Menjalankan

Jalankan server PHP menggunakan:

```bash
php -S localhost:8000
```

Kemudian buka browser:

```text
http://localhost:8000
```

## Pengujian

- Menambah produk
- Menghapus produk
- Mengosongkan keranjang
- Mengubah tema Light/Dark
- Menguji input tidak valid
